# وضع التحفيظ المقفل — دليل الإضافة

أُضيف إلى التطبيق **وضع تحفيظ صارم** يعمل كالتالي:

1. **رفع صوت المحفّظ** الذي تفضّل سماعه.
2. **التقطيع** حسب اختيارك: صفحة / آيات / أرباع / أحزاب / أجزاء.
   - عبر السيرفر (تقطيع دقيق قرآنيًّا)، أو
   - بمقاطع جاهزة تختارها بنفسك، أو
   - ملف واحد كامل.
3. **تحديد عدد مرات التكرار** لكل مقطع (1 إلى 50).
4. **قفل الجهاز**: تثبيت الشاشة + كتم كل الإشعارات + منع فتح أي تطبيق آخر، حتى تُنهي كل التكرارات.
5. **تسجيل صوتك** في كل تكرار، ويُحفظ ملف مستقل لكل تكرار.

---

## درجة «القفل» — اقرأ هذا جيدًا

القفل الكامل غير القابل للهروب على أندرويد متاح فقط حين يكون التطبيق **Device Owner**. لذلك للإضافة وضعان:

| الوضع | كيف يُفعَّل | مدى الصرامة |
|------|-----------|-------------|
| **تثبيت الشاشة (افتراضي)** | تلقائيًّا عند بدء الجلسة | يمنع الخروج العادي والإشعارات؛ يمكن للمستخدم الخروج بالضغط المطوّل على «رجوع + المهام». مناسب للانضباط الذاتي. |
| **قفل كامل (Kiosk)** | بجعل التطبيق Device Owner مرّة واحدة عبر ADB | لا خروج إطلاقًا حتى تنتهي التكرارات. |

### تفعيل القفل الكامل (Device Owner) — مرّة واحدة لكل جهاز
على جهاز **لا يحتوي حسابات Google مضافة** (أعد ضبطه أو احذف الحسابات أولًا):
```bash
adb shell dpm set-device-owner com.yourcompany.quran_splitter/.QuranAdminReceiver
```
بعدها تكتشف الإضافة الوضع تلقائيًّا وتدخل قفلًا كاملًا أثناء الجلسة. لإلغائه:
```bash
adb shell dpm remove-active-admin com.yourcompany.quran_splitter/.QuranAdminReceiver
```
> هذه الطريقة مخصّصة للاستخدام الشخصي/المؤسسي على أجهزة مخصّصة، وليست لتوزيع عام عبر Play.

## الأذونات المطلوبة (تُطلب عند أوّل استخدام)

- **الميكروفون** — لتسجيل التسميع.
- **عدم الإزعاج (DND)** — لكتمٍ تامّ للإشعارات. التطبيق يفتح لك شاشة منح الإذن؛ يمكن التخطّي والعمل بدونه (مع كتم أقل اكتمالًا).

أُضيفت تلقائيًّا في `AndroidManifest.xml`:
`RECORD_AUDIO`, `ACCESS_NOTIFICATION_POLICY`, `WAKE_LOCK`، ومستقبِل مدير الجهاز.

## الملفات الجديدة

```
app_src/lib/models/memo_segment.dart        ← نموذج المقطع وإعدادات الجلسة
app_src/lib/services/session_lock.dart       ← القفل + DND + إبقاء الشاشة (قناة أصلية)
app_src/lib/services/recite_player.dart      ← تشغيل صوت المحفّظ + تسجيل المتعلّم
app_src/lib/services/segment_source.dart     ← بناء المقاطع من zip السيرفر أو من ملفات
app_src/lib/screens/memorize_setup.dart      ← شاشة التجهيز (المصدر/التكرار/الخيارات)
app_src/lib/screens/memorize_session.dart    ← الجلسة المقفلة (استماع→تسميع→تكرار)
app_src/android/MainActivity.kt              ← معالج القناة الأصلية (lock/DND)
app_src/android/QuranAdminReceiver.kt        ← مستقبِل مدير الجهاز
app_src/android/device_admin.xml             ← سياسات مدير الجهاز
```
الملفّات الأصلية (Kotlin/XML) تُنسَخ تلقائيًّا أثناء بناء `build-android.yml` مع ضبط اسم الحزمة و`minSdk = 23`.

## أين أبدأ؟
من الشاشة الرئيسية: بطاقة **«وضع التحفيظ المقفل»** في الأعلى. والتحميل العادي للمقاطع لا يزال متاحًا أسفلها.

التسجيلات تُحفظ في مجلّد جلسة باسم `memorize_<وقت>` داخل مجلّد مستندات التطبيق، ويُعرَض مساره في نهاية الجلسة.
